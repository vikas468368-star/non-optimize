## About The Project

**Non-Optimize** is a front-end web project developed using HTML, CSS and JavaScript.

The project focuses on understanding the fundamentals of web development while experimenting with website structure, styling, visual effects and interactive functionality.

The project follows a simple approach:

```text
HTML        →        Structure
CSS         →        Design
JavaScript  →        Interaction
```

---

## Project Objective

The primary objective of this project is to build a simple website using core web technologies without depending on external frameworks.

The project provides practical experience with:

- HTML page structure
- CSS styling and layouts
- JavaScript functionality
- Browser-based development
- Front-end project organization
- Git and GitHub workflow

## Installation

Clone the repository:

```bash
git clone https://github.com/vikas468368-star/non-optimize.git
```

Navigate to the project:

```bash
cd non-optimize
```

Open the following file:

```text
index.html
```

The website can be opened directly in any modern web browser.

No framework or package installation is required.
