## ✨ About The Project

**Non-Optimize** is a front-end web project created to explore and demonstrate the fundamentals of building an interactive website using **HTML, CSS, and JavaScript**.

The project keeps the implementation simple and focuses on the core building blocks of a website:

> **HTML → Structure**  
> **CSS → Design**  
> **JavaScript → Interaction**

It is suitable for learning, experimentation, and understanding how the three core front-end technologies work together.

---

## 🎯 Project Goals

The main goals of this project are:

- 🧱 Build a complete webpage using HTML
- 🎨 Create a visually appealing interface using CSS
- ⚡ Add interaction using JavaScript
- 🖥️ Understand basic front-end architecture
- 🧪 Experiment with web design concepts
- 📚 Practice organizing a simple web project

## 🧩 How It Works

The project follows a simple three-layer front-end architecture:

```text
             🌐 WEBSITE
                  │
        ┌─────────┼─────────┐
        │         │         │
        ▼         ▼         ▼
     HTML       CSS    JavaScript
        │         │         │
        ▼         ▼         ▼
   Structure   Design   Interaction
        │         │         │
        └─────────┼─────────┘
                  ▼
          💻 FINAL WEBSITE
```

### HTML

Provides the content and structure of the webpage.

### CSS

Controls the appearance, layout, spacing, colors, and visual presentation.

### JavaScript

Adds functionality and user interaction to the website.
