# 🌈 About

**Non-Optimize** is a simple and experimental front-end website created using the three fundamental technologies of web development:

```text
HTML        →        Structure
CSS         →        Design
JavaScript  →        Interaction
```

The project focuses on understanding the fundamentals of web development while experimenting with layouts, styling, animations and interactive elements.
